# 개인용 만화 라이브러리: 현재 기능과 다음 단계

2026-09-13 기준. 기존 YACReader를 확장한 개인 Windows 앱이다. 전체 사용
경험을 완성했다고 보기는 이르지만, 개별 작품 관리와 검토 후 메타데이터
저장, 선택 작품 OCR의 정상 중단·재개까지 연결되어 있다. 전체 라이브러리
자동 처리는 아직 제공하지 않는다. 아래 상태는 코드와 검증 기록을 기준으로
하며, 실제 작품의 식별 정답률이나 수만 권의 사용성을 뜻하지 않는다.

## 현재 사용할 수 있는 기능

| 기능 | 상태와 남은 한계 |
| --- | --- |
| 원본 위치를 유지하는 Grid/List와 뷰어 | 기존 기반 사용. 압축작품 및 직접 이미지를 담은 작품 폴더 지원. 복잡한 중첩 폴더는 별도 과제. |
| 작가·태그·Favorite·Reading·Recent 탐색 | 기존 목록과 연결. 작가·태그 정확 검색과 복합 조건 지원. 대규모 집계 성능은 별도 검증 필요. |
| 앞뒤 최대 3장 OCR | 일본어·한국어, 자동 언어 비교, 영역 탐지, 선택 영역 재판독, CPU 4·8·16스레드와 선택 NVIDIA 실행 지원. |
| 제목·작가·발행자/서클 후보 | 근거 페이지 표시, 같은 후보 통합, 역할 구분. OCR 점수는 정답 확률이 아니며 불확실한 이름은 검토 필요. |
| 파일명으로 대조 | 앞뒤 범위에 식별 후보가 없으면 추가 페이지를 읽지 않고 파일명 힌트의 검토·대조로 진행. 파일명은 확인된 작품 정체성이 아님. |
| 외부 메타데이터 대조 | E-Hentai와 AniList 후보 검토. 작가와 서클을 구분하고 출처를 기록. 실제 검색 성공률은 별도 확인 대상. |
| 검토 후 개별 저장 | 기본은 빈 값을 채우며 덮어쓰기는 명시 선택. 현재 작품·원본·검토 결과가 맞는지 다시 확인하고 저장. |
| 선택 작품의 영구 OCR 기록 | 페이지 결과·검증 정보를 별도 작업 DB와 캐시에 기록. 정상 중지 후 남은 페이지만 이어 읽기, 완료 결과 재열기 지원. |
| 실행 진행·중지 | 실행 환경 검사 단계·파일 수·용량 표시, 실제 처리 장치 표시. 준비 중 중지 시 미리보기 보존 확인. 정상 중지의 미처리 표시는 후속 검증 중. |

## 검증 상태

- Windows 빌드와 설치, 설치 후 OCR, 다운로드한 실행본의 재검사 흐름을 유지한다.
- `aa8267fc`의 Windows 실행 `34731633774`는 전체 성공했다. 필수 패키지
  검사에서 installed21, downloaded152, staged8, store25, 모의 오류18이
  실패·건너뜀 없이 통과했다. 초기 환경의 선택 검사 건너뜀과 구분한다.
- 같은 소스의 로컬 전체 실행본에서 native53/store25/실제 합성 CPU 전환5/
  GPU5/명시적 CPU4/모의 오류18을 통과했다. 다섯 GPU 작업자를 NVIDIA에서
  관측했다. 이후 화면 수정은 별도 검증하며 이전 성공으로 대신하지 않는다.
- 합성 회귀, 실제 GPU 프로세스 관측, 실제 작품의 문자/역할 정확도는
  서로 다른 근거다. 실제 작품의 이미지·경로·OCR 결과·정답은 저장소에 넣지 않는다.

## 다음 구현 순서

1. **선택 작품 처리 안정화**: 최신 실행본의 중지·재개·완료 검토와 실제
   장치 검증. 완료 직후 중지가 자동 조회로 이어지지 않게 한다.
2. **실패·강제 종료 복구**: 이전 작업자 종료와 캐시 유효성을 확인한 뒤
   선택한 실패 작업만 재개한다. 실패 기록을 남기고 중복 GPU 실행을 막는다.
3. **여러 작품의 검토 목록**: 페이지 근거 있음, 파일명 대조 필요, 후보 충돌,
   오류 등을 모아 보여주고 사용자가 확인한 항목을 구분한다.
4. **여러 작품의 영구 작업 큐**: 선택 범위 등록, 전체/개별 일시정지와 재개,
   실패 항목 재시도, 진행 현황, 캐시 크기와 정리 정책을 연결한다. 기존
   선택 작품용 저장소·캐시·실행기를 기반으로 확장한다.
5. **검토한 항목의 일괄 저장**: 저장 전 변경 내역을 보여주고 충돌한 작품은
   제외한다. 출처와 저장 기록, 되돌리기 범위를 설계한 뒤 연결한다.
6. **라이브러리 규모 대응**: 합성 DB로 목록·검색·태그 집계의 반응성을
   먼저 확인하고, 전체 원본 처리는 별도로 허용된 범위에서 진행한다.

## 후순위 선택 기능

- 작가의 별명·번역명 연결과 잘못 연결한 이름의 분리. 추정만으로 병합하지 않는다.
- 추가 메타데이터 공급자, 중복 작품 표시, 더 복잡한 작품 폴더 처리.
- 자주 쓰는 필터와 검토 편의 개선. 실제 사용에서 불편한 부분을 우선한다.

다른 OS 지원 확대, 배포용 서명·자동 업데이트, 원본 일괄 이름 변경은 현재
우선순위가 아니다. 기존 다른 OS 코드를 일부러 제거할 필요도 없다.
원본·운영 DB·현재 설치 앱은 시험 작업에서 보존한다.
